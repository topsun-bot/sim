## 命令速查

```bash

cd /home/gy/code/sim
PYTHONPATH=. python -m replay.cli inspect data/eda9cc2192f7.mcap
PYTHONPATH=. python -m replay.cli run --mcap data/eda9cc2192f7.mcap --meta data/eda9cc2192f7.meta.json

# pip 安装后
pip install -e .
replay inspect data/eda9cc2192f7.mcap

# Docker

docker compose run --rm replay
```
